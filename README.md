# Digital Signature System

Academic web application developed to manage PDF documents, cryptographic key pairs, and digital signatures.

## Overview

This project was developed as an academic integration project for Computer Engineering. The system allows users to upload PDF documents, generate cryptographic key pairs, digitally sign documents, verify signatures, and check file integrity using hashes.

The goal of the project was to apply web development, database design, authentication, file management, and basic cryptographic concepts in a practical web application.

## Features

* User authentication
* PDF document upload and management
* Public/private key pair generation
* Digital signature creation and verification
* Document integrity verification using hashes
* Signature tracking by user and document
* Protected views for authenticated users

## Technologies

* PHP
* Laravel
* MySQL
* Blade
* Tailwind CSS
* OpenSSL
* Git

## What I learned

* Building a web application using the MVC pattern
* Managing authentication and protected routes
* Designing relational database tables for users, documents, keys, and signatures
* Handling file uploads and downloads
* Applying digital signature and hash verification concepts
* Organizing controllers, models, migrations, and views in Laravel

## Project status

Academic project completed as a first functional version. Future improvements could include a more polished user interface, better error handling, stronger key management, and a more detailed audit/history system.
